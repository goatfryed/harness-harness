# Planning leverage with a fixed coding worker

**Evidence reviewed through:** 2026-11-23. This note assesses the [default-loop assumption](../../concepts/default-loop.md) and complements [thin orchestration and smart planners](../thin-orchestration-smart-planners.md) and [adaptive model leads](../adaptive-model-leads.md); it looks beyond their PAUSE/DCAS comparisons. All four sources below are preprints. The question is whether adding, informing, or timing planning or guidance improves coding outcomes with the worker held fixed, and at what resource cost.

## Strongest result

**Selective stronger-model advice improved a fixed executor's coding success relative to several placement controls, but not at matched total spend or with a fully thin orchestrator.** In ARIA, a fixed Gemini Flash executor with Gemini Pro advice achieved **48.0%** on 50 SWE-bench Verified-Mini tasks, versus **28.0%** with random advice placement and **41.3%** with a start/end-and-stall heuristic. The three policies averaged **2.78, 2.53, and 2.75** advisor consultations per episode, respectively. Costs were **$22.09, $17.33, and $21.50**; results are means over three seeds. The advisor-only agent scored **62.0% at $45.90** and the executor alone **18.0% at $11.48** [1]. The advice is not necessarily a single upfront plan, and the system retains Magentic-One's model-based orchestration. The close-volume heuristic comparison is more relevant than claiming advice is free or an equal-cost match; the 50-task test and differing realized costs leave uncertainty.

## Synthesis and counterevidence

These studies support **conditional leverage**, not a proven model-tier assignment. A stronger model can improve a fixed executor through timely advice or relevant evidence; information and the timing of its delivery matter. But the strongest model is not guaranteed to be best used as planner: ARIA's strong solo agent is more accurate, and its advisor system still uses a substantive model orchestrator. In [2], planning can displace execution under a shared cap; in [3], a self-planning scaffold helps the weakest model while not improving the stronger models' measured accuracy. Existing [Cohere findings](../thin-orchestration-smart-planners.md) also warn that cheaper implementation can reduce quality. None of these studies isolates deterministic dispatch or proves that a mid-tier builder is optimal for new development, cross-module integration, or changing requirements.

**Practical evaluation implication, not an architectural conclusion:** compare capable solo, fixed-builder self-planning, fixed-builder stronger advice, and stronger solo on identical tasks and verification. For timing, vary upfront, post-investigation/pre-edit, and exception-triggered advice with the same advisor, information, and intervention authority where feasible. Use both a common total dollar/latency cap and quality–cost curves; account for investigation, planning, downstream worker changes, retries, verification, and any policy-training cost. Pair task outcomes and report uncertainty and regressions as well as gains. Give planners actual issue and repository evidence, and reserve enough execution budget. A useful plan is only valuable if the builder can implement and verify it.
