---
description: Merge upstream into this harness
---

Merge remote `upstream` into the current branch.
If the current branch is not main, ask for confirmation.

This harness may have been converted to a different agent runtime and streamlined to strip unnecessary features.
Therefore, merge conflicts - especially about deleted files - are not unusual. Also merges might introduce new files that need movement or modification.
Handle conflicts, file introduction and added references in compliance with [/harness-streamline](harness-streamline.md) and [/harness-convert](harness-convert.md]. Check README.md and ask, if in doubt.
